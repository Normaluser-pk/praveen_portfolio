# Praveen Kumar J — Portfolio

A responsive personal portfolio built from the information in the supplied resume.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`.
5. Save and open the generated GitHub Pages URL.

Before publishing, replace the placeholder LinkedIn/GitHub links with the actual profile URLs.
